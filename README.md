# Quantitative-Backtesting-Analytics-Dashboard

Quantitative Backtesting & Analytics Dashboard – Python · Streamlit · Pandas · NumPy · Plotly

- Backtest algorithmic strategies across historical datasets
- Data interpretation pipelines using Pandas and NumPy to transform raw financial data into visual performance reports
- Statistical analysis modules including rolling averages, variance analysis and correlation
- Interactive dashboards enabling teams to evaluate model reliability and optimize strategy parameters

## Quick Start

```bash
pip install -r requirements.txt
streamlit run app.py
```
